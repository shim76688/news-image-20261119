# The World Today — Thursday 19 November 2026

A one-image front page summing up the world's news of Thursday 19 November 2026,
drawn entirely in code by `main.ts` (pure Node 22 standard library, no network).

Stories: the first-ever Trump–Xi–Putin trilateral summit in Shenzhen; three oil tankers
on fire after hitting mines near the Strait of Hormuz; the world court ruling on
Myanmar's alleged Rohingya genocide; GTA VI launching worldwide; Anthropic's record
$107.3bn IPO; and a magnitude 5.7 quake in Kumamoto, Japan.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` — it writes
`out/entry.png` (1024x1024, deterministic: two runs produce identical bytes).
